# Data

This folder contains all datasets used across different components of the project.

Data used in **Baseline**, **Extension 1**, **Extension 1 Clustering Analysis**, and **Extension 2** have different internal structures depending on the specific pipeline requirements.

---

## 📂 Folder Structure
```bash

data/
│
├── raw/ # Original raw datasets
├── processed/ # Preprocessed and cleaned datasets used in baseline pipeline
│
├── extension1/ # Data formatted for Extension 1 pipeline
├── extension1_clustering/ # Data used for Extension 1 cluster analysis
├── extension2/ # Data structured for Extension 2 embedding-based pipeline
│
└── pycache/ # Auto-generated Python cache files
```
