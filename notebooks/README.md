# Baseline and Extension Analysis

This folder contains two Jupyter notebooks focused on the comparison between the baseline model and its extensions.

## 01_baseline_ext1.ipynb

This notebook provides a detailed comparison between the baseline model and Extension 1.

The analysis includes:

- A thorough evaluation of the additional features introduced in Extension 1  
- An assessment of their impact on model performance  
- A comparison of results between the baseline and the extended model  

After the performance comparison, the notebook presents:

- A detailed interpretation of the identified clusters  
- An analysis of feature distributions across different subgroups  
- An evaluation of how prediction errors affect different groups  

The goal of this notebook is to understand both the quantitative improvement and the structural changes introduced by the additional features.

## 02_baseline_ext1_ext2.ipynb

This notebook introduces the UMAP + HDBSCAN methodology for clustering.

The analysis includes:

- A presentation of the UMAP dimensionality reduction technique  
- The application of HDBSCAN for cluster identification  
- Interpretation and evaluation of the obtained clusters  
- Visualization using a UMAP plot  

After the clustering analysis, the notebook presents:

- The construction of cluster embeddings  
- The model setup and training configuration  
- Training curves and performance monitoring  

Finally, the notebook provides:

- A presentation of results  
- A comparison between the Baseline, Extension 1, and Extension 2 models
